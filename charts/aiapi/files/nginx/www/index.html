安装脚本

选择你的客户端并复制命令。页面会根据当前访问域名自动生成安装地址，不需要在文档里写死站点 URL。

批量配置时可以提前设置 EST_API_KEY。脚本也支持 EST_MODEL、EST_API_BASE_URL、EST_ANTHROPIC_BASE_URL 和客户端专用 Home 目录变量。

客户端配置摘要

页面只展示关键结果，具体文件写入由脚本处理并自动备份。

Codex OpenAI Responses

配置 provider、base URL、默认模型和 API Key。

Claude Code Anthropic Messages

配置 ANTHROPIC_BASE_URL 和 ANTHROPIC_AUTH_TOKEN。

安全 自动备份

修改本地配置前都会生成带时间戳的备份。

接入流程

不同客户端协议不同，但都使用同一个 AIAPI Key 和当前站点作为网关入口。

获取 Key

打开 AIAPI 后台，创建或复制你的 API Key。

执行脚本

按系统复制上方命令，脚本会交互式询问密钥。

重启客户端

如果客户端正在运行，重启后会加载新的网关配置。

开始使用

后续客户端请求会走当前 AIAPI 站点。

其他 Agent 应用

支持 OpenAI-compatible 或 Anthropic-compatible 配置的客户端，通常只需要填入 Base URL、API Key 和模型名。

Base URL 当前 Host

OpenAI-compatible 客户端通常使用 /v1，Anthropic-compatible 客户端使用站点根地址。

API Key EST_API_KEY

建议通过环境变量或客户端密钥管理功能保存。

Model gpt-5.6-sol

后台开放更多模型后，可在客户端模型字段切换。
